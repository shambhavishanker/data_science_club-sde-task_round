# Hackathon Registration Website

A responsive frontend website for hackathon registration.

## Live Website
https://hackathon-registration-three.vercel.app

## Features
- Responsive modern UI
- Home, About, Schedule, Prizes, Sponsors, and Registration sections
- Interactive horizontal schedule timeline
- Countdown timer
- Dark mode
- Registration form validation
- Animations and transitions

## Tech Stack
React, TypeScript, Vite, CSS

## Deployment
Deployed on Vercel.
