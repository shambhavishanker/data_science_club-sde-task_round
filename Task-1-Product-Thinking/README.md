Task 1- Product Thinking

App- Roblox
Feature introduced- Game Collections

Problem:
I’ve played a lot of games on Roblox over time, and one thing I find inconvenient is finding a game I played before and want to return to. The games in the Continue section keep getting rearranged and sometimes games I haven’t played appear there while games I have played disappear from the list. While games can be favorited, there isn’t an easy way to properly organize them and as the list of games played grows, finding a particular game again can take time, especially if I don’t remember its exact name.

Solution:
I would introduce a Game Collections feature that lets users save games and organize them into their own collections, similar to how YouTube has playlists where users can save and organize videos. Users could create collections based on genre or how they want to play, such as horror, mystery, roleplay, games to play with friends, Want to play, etc. 
A game could also be saved in more than one collection.

Unlike the Continue section, these collections would be completely organized by the user and wouldn’t keep changing based on recently played or recommended games. This would make it easier to save games for later, find older games again, and keep different types of games organized instead of having to search through one constantly changing list.
